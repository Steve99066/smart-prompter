# الملقّن الذكي — النسخة 0.2

هذه نسخة أولية مجانية لا تستخدم Claude API ولا OpenAI API.

## ما الذي تفعله؟
1. تلصق السكريبت.
2. يقسمه التطبيق إلى مقاطع.
3. ينطق المقطع الحالي.
4. يستمع إلى كلامك.
5. يقارن كلامك بالمقطع.
6. ينتقل تلقائيًا عند تجاوز نسبة المطابقة.

## الملفات
- index.html: واجهة التطبيق.
- styles.css: التصميم.
- app.js: منطق التطبيق.
- manifest.webmanifest: معلومات تثبيت التطبيق.
- service-worker.js: تشغيل التطبيق دون اتصال بعد أول تحميل.
- icons/: أيقونات التطبيق.
- START_HERE.html: دليل استخدام مبسط.

## مهم
لا تفتح index.html مباشرة وتتوقع أن يعمل الميكروفون دائمًا. الأفضل تشغيله عبر localhost على الكمبيوتر أو نشره على رابط HTTPS.


## تعديلات الإصدار 0.2
- يستمر التطبيق في الاستماع تلقائيًا بعد الكلام غير المطابق.
- حذف زر تحميل المثال.
- حذف وصف النسخة التجريبية من أعلى التطبيق.
- الأوامر الصوتية أصبحت: إعادة، رجوع، أكمل.
