ابدأ من هنا

لا تحتاج أن تفهم البرمجة. اتبع الخطوات بالترتيب.

الطريقة الأولى: التجربة على الكمبيوتر

  1. فك ضغط الملف في مجلد جديد.
  2. ثبّت برنامج Visual Studio Code من موقعه الرسمي.
  3. افتح Visual Studio Code.
  4. من قائمة File اختر Open Folder، ثم اختر مجلد المشروع.
  5. افتح تبويب Extensions من الجهة اليسرى.
  6. ابحث عن إضافة اسمها Live Server وثبّتها.
  7. افتح ملف index.html.
  8. اضغط زر Go Live أسفل نافذة البرنامج.
  9. سيفتح التطبيق في Chrome على رابط محلي.
  10. عندما يطلب إذن الميكروفون اختر سماح.

طريقة تجربة سريعة

  1. ألصق سكريبتًا قصيرًا في مربع النص.
  2. اضغط «تجهيز السكريبت».
  3. راجع المقاطع.
  4. اضغط «بدء جلسة التلقين».
  5. اضغط «ابدأ».
  6. ضع سماعة في أذن واحدة حتى لا يسمع الميكروفون صوت الملقّن بوضوح.
  7. كرر الجملة التي تسمعها.

قبل التجربة على الهاتف

يحتاج الهاتف إلى رابط آمن يبدأ بـ HTTPS حتى تعمل صلاحية الميكروفون والتثبيت بصورة صحيحة. بعد نجاح التجربة على الكمبيوتر، ارفع ملفات المشروع إلى استضافة مجانية مثل GitHub Pages أو أي استضافة ثابتة.

أوامر البرنامج

  • إعادة: يعيد المقطع الحالي.
  • رجوع: يعود إلى المقطع السابق.
  • أكمل: ينتقل إلى المقطع التالي، أو يستكمل الجلسة إن كانت متوقفة.

عند حدوث مشكلة

صوّر الشاشة أو انسخ رسالة الخطأ كاملة. لا تعدّل ملفات الكود بنفسك في البداية.
